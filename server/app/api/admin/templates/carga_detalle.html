Agregar al camión

Se captura en bultos —cajas o piezas, como se levantan con las manos— y el sistema los convierte a unidad base al guardar. La multiplicación ocurre una sola vez, aquí: es lo que evita que media empresa cuente cajas y la otra media piezas.

Confirmar

Al confirmar pasan tres cosas en una sola transacción: se escribe el movimiento en el libro mayor, la bodega baja y el camión sube, y el teléfono del vendedor recibe la carga con su detalle en la siguiente sincronización.

El movimiento del libro mayor no se puede borrar. Si algo sale mal se corrige con un documento compensatorio, que deja rastro de las dos cosas.
