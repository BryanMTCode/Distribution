{# Plantilla base del panel de operación. ─────────────────────────────────────────────────────────────────────────── SIN CDN, SIN JAVASCRIPT DE TERCEROS ─────────────────────────────────────────────────────────────────────────── El panel corre en el servidor de la oficina, detrás del túnel. Traer HTMX o una hoja de estilos de un CDN convertiría una herramienta de red local en una que **depende de internet**: el día que se caiga el enlace, la oficina se queda sin poder capturar precios aunque el servidor esté perfecto. Todo es HTML renderizado en el servidor con formularios normales. Funciona sin JavaScript, en cualquier navegador, y no hay nada que se pueda romper al actualizar una dependencia. HTMX entra el día que una pantalla concreta lo necesite —búsqueda mientras se escribe, por ejemplo— y entonces se versiona el archivo en el repositorio, no se apunta a un CDN.
